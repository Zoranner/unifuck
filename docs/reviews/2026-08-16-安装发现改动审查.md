# unifuck 安装发现改动审查报告

## 评审范围

本次仅审查当前未提交的 Unity / 团结引擎 Hub 与 Editor 安装发现改动，以及直接关联的 Rust、Slint 和依赖清单。重点是默认托管目录扫描、Hub 配置记录合并和路径校验；不评价第三方程序修改行为。

## 评审依据

- 仓库的 `README.md`、`.editorconfig`、`.gitattributes` 与 Cargo workspace 配置。
- 当前未提交 diff，主要涉及 `crates/unifuck/src/discovery.rs` 与 `crates/unifuck/src/core/group.rs`。
- Rust 工程评审通用基线及 Rust 专项清单。

## 总体结论

新增的 Unity 默认目录扫描能够覆盖当前机器上 `secondaryInstallPath.json` 指向的 `C:\Program Files\Unity\Hub\Editor`，并通过可执行文件存在性校验，方向正确。

本轮复核后，默认目录来源、前缀并集和 JSON 优先级已收敛。Hub 程序目录下的 `Editor` 子目录不是有效安装路径，先前对此的回归判断撤回。路径去重键进一步解析真实路径别名，避免 junction、symbolic link 或 8.3 路径绕过文本规范化。

本次发现的四项问题均已完成复核或修正：Hub 程序目录扫描意见已撤回，其余三项已由前缀并集、统一路径键和准确注释处理。未发现新的阻断问题。

## 整改优先级建议

### 收敛发现来源

- 默认路径只使用 `<前缀>\<Vendor>\Hub\Editor`，不扫描 Hub 程序目录下不存在的 `Editor` 子目录。
- 将多个前缀作为并集扫描，并在最终合并边界以真实路径去重。

### 补齐回归测试

- JSON 与默认目录的大小写、尾随分隔符、`..`、短路径和链接路径去重。
- `secondaryInstallPath.json` 与标准 `ProgramFiles` 同时存在。
